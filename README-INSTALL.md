# Brick Hill Client Installation

1. Open the Brick Hill Client page.
2. Click **Install Brick Hill Client**.
3. Open your Downloads folder.
4. Right-click `install-brickhill.ps1` and choose **Run with PowerShell**.
5. The script downloads the complete client to `%LOCALAPPDATA%\\BrickHill` and registers the `brickhill://` protocol.
6. Return to `https://brickhill.onrender.com/`.
7. Log in, choose a game, and click **Play**.
8. Windows should ask whether you want to open **Brick Hill**. Choose **Open**.
9. The launcher starts the original Brick Hill client with the selected game ticket.

If Play still does not open the client, run the installer again and then try Play once more.
