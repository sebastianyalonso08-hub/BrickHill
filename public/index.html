Brick Hill Client Tutorial · Windows Setup
How to Install and Launch Brick Hill

Follow these steps once to install the Brick Hill client. After setup is complete, you can launch the game directly from the website.

  1. Download the client installer.
    Click Install Brick Hill Client on the Brick Hill Client page. Your browser will download install-brickhill.ps1. This script installs the full client into your Windows AppData folder.
  2. Open your Downloads folder.
    Find the downloaded install-brickhill.ps1 file in your Downloads folder.
  3. Run the installer with PowerShell.
    Right-click install-brickhill.ps1 and choose Run with PowerShell. The installer downloads the complete Brick Hill client, installs it, and registers the brickhill:// launcher protocol.
  4. Return to Brick Hill.
    Go back to brickhill.onrender.com in your browser. You do not need to download the client again.
  5. Log in.
    Sign in to your Brick Hill account. You must be logged in before starting a game.
  6. Choose a game and press Play.
    Open the Games page, choose the game you want to play, and click the green Play button.
  7. Allow Brick Hill to open.
    Windows may show a message asking whether you want to open Brick Hill. Choose Open or Allow. This launches the installed Brick Hill client.
  8. Wait for the client to start.
    The launcher starts the original Brick Hill client and connects it through the Brick Hill network bridge. The client files are installed automatically, so you do not need to move the EXE files manually.
First-time setup tip: You only need to install the client once on each Windows computer. If clicking Play does nothing, return to this tutorial and run the installer again.
